StmPy Studio は編集・ビルド・書き込みまで。StmPy は Python 構文を STM32 HAL 上の C に翻訳し、手書き C と同じ速さで動きます（チップ上にインタプリタは不要）。

チュートリアルは英語／中国語のみです。日本語ページでは英語版にフォールバックします。
