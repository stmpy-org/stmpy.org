# PWM

PWM 输出固定频率的方波，通过改变高电平所占的比例（占空比）来调节 LED 亮度、电机转速，或者控制舵机的角度。

只要写引脚，编译器会找到引脚对应的定时器通道，并算好分频。

```python
from stmpy import PWM, delay_ms

servo = PWM("PA1", freq=50, duty=0.075)    # 舵机：50 Hz，1.5 ms 高电平
led = PWM("PA8", freq=1000)

def main():
    while True:
        servo.pulse_us(1000)
        led.duty(0.2)
        delay_ms(500)
        servo.pulse_us(2000)
        led.duty(0.8)
        delay_ms(500)
```

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `pin` | 必填 | 输出引脚，比如 `"PA1"` |
| `freq` | 必填 | 频率，单位 Hz，整数 |
| `duty` | 0.0 | 初始的占空比，0.0 一直是低电平，1.0 一直是高电平 |
| `timer` | 0 | 引脚属于多个定时器时，用它指定定时器编号。0 表示按引脚表的顺序取第一个 |
| `complement` | `""` | 互补输出的引脚，见"互补输出" |
| `dead_ns` | 0 | 死区时间，单位纳秒，只有写了 `complement` 才能用 |

## 方法

| 方法 | 说明 |
|---|---|
| `duty(value: float)` | 设置占空比，超出 0.0-1.0 的值按边界处理 |
| `pulse_us(us: int)` | 设置每个周期里高电平的时间，单位微秒。超过周期时一直是高电平 |

修改在当前周期结束后才生效，不会输出半截的脉冲。

## 同一个定时器上的多个输出

一个定时器有 4 个通道，几个 PWM 可以共用一个定时器，但是：

1. **频率必须相同**，因为它们共用一个计数器。
2. **一个通道只能有一个输出。** 比如 PA2 和 PB10 都是 TIM2 的 CH3，不能同时用。
3. **STM32F1 上，引脚必须在同一种重映射里。** 编译器会选出能同时引出所有引脚的那一种。

| 写法 | 结果 |
|---|---|
| PA0 + PA1 | TIM2，不重映射 |
| PA0 + PB10 | TIM2，部分重映射 2 |
| PA15 + PB11 | TIM2，完全重映射 |
| PA0 + PA2 + PB3 | 报错：PA0 和 PA2 一起用时只能不重映射，PB3 却要部分重映射 1 或完全重映射 |
| PA0（50 Hz）+ PA1（1000 Hz） | 报错：频率不同 |
| PA2 + PB10 | 报错：都是 TIM2 的 CH3 |

频率不同时的报错：

```
main.py:3: ValueError: b runs TIM2 at 1000 Hz but a at 50 Hz, PWM outputs on one timer need the same freq
```

PWM 占用的定时器不能再用作 [`Timer`](../timer/)、[`Capture`](../capture/) 或 [`Encoder`](../encoder/)，反过来也一样。

## 引脚和定时器

STM32F103 的常用引脚：

| 定时器 | 重映射 | CH1 | CH2 | CH3 | CH4 | 可用芯片 |
|---|---|---|---|---|---|---|
| TIM1 | 无 | PA8 | PA9 | PA10 | PA11 | 全部 |
| TIM1 | 完全 | PE9 | PE11 | PE13 | PE14 | 100、144 脚 |
| TIM2 | 无 | PA0 | PA1 | PA2 | PA3 | 全部 |
| TIM2 | 部分 1 | PA15 | PB3 | PA2 | PA3 | 全部 |
| TIM2 | 部分 2 | PA0 | PA1 | PB10 | PB11 | 有 PB10、PB11 的封装 |
| TIM2 | 完全 | PA15 | PB3 | PB10 | PB11 | 有 PB10、PB11 的封装 |
| TIM3 | 无 | PA6 | PA7 | PB0 | PB1 | 全部 |
| TIM3 | 部分 | PB4 | PB5 | PB0 | PB1 | 全部 |
| TIM3 | 完全 | PC6 | PC7 | PC8 | PC9 | 64 脚及以上 |
| TIM4 | 无 | PB6 | PB7 | PB8 | PB9 | xB 及以上 |
| TIM4 | 重映射 | PD12 | PD13 | PD14 | PD15 | xB 及以上的 100、144 脚 |
| TIM5 | 无 | PA0 | PA1 | PA2 | PA3 | xE / xG |
| TIM8 | 无 | PC6 | PC7 | PC8 | PC9 | xE / xG |

- 重映射由编译器选，不用写。
- 一个引脚属于多个定时器时，不写 `timer` 就按表中的顺序取第一个：PA0-PA3 取 TIM2（xE 及以上可以用 `timer=5` 换成 TIM5），PC6-PC9 取 TIM3（可以用 `timer=8`）。
- F100 还有 TIM12-TIM17，F101、F103 的 xF、xG 还有 TIM9-TIM14。
- **STM32F4** 的每个引脚单独选复用功能，没有重映射，同一个定时器的通道可以任意搭配引脚，能用的引脚也更多。

其他芯片的引脚以编辑器的补全和编译报错为准。

## 互补输出

TIM1 和 TIM8 的 CH1-CH3 各有一个反相的输出，用来驱动半桥、全桥和三相电机。

```python
from stmpy import PWM

# PA8 为高时 PB13 为低，切换时两个都保持低电平 500 纳秒
u = PWM("PA8", freq=20000, complement="PB13", dead_ns=500)
v = PWM("PA9", freq=20000, complement="PB14", dead_ns=500)
w = PWM("PA10", freq=20000, complement="PB15", dead_ns=500)

def main():
    u.duty(0.5)
    v.duty(0.25)
    w.duty(0.75)
```

> **`dead_ns` 默认是 0，也就是没有死区。** 驱动半桥时一定要写，否则上下两个管子切换时会同时导通，可能烧毁。值要看功率管和驱动芯片的手册，常见的是几百纳秒到几微秒。驱动芯片自带死区时可以不写。

STM32F103 的互补输出引脚：

| 定时器 | 重映射 | CH1N | CH2N | CH3N | 可用芯片 |
|---|---|---|---|---|---|
| TIM1 | 无 | PB13 | PB14 | PB15 | 48 脚及以上 |
| TIM1 | 部分 | PA7 | PB0 | PB1 | 全部 |
| TIM1 | 完全 | PE8 | PE10 | PE12 | 100、144 脚 |
| TIM8 | 无 | PA7 | PB0 | PB1 | xE / xG |

- 同一个定时器上的互补输出，`dead_ns` 必须相同，硬件只有一个死区设置。
- 死区按定时器时钟的整数倍向上取整。72 MHz 时最长 14 微秒，越长步长越大：1.76 微秒以内每步约 14 纳秒，14 微秒附近每步约 222 纳秒。在编辑器里悬停在对象上能看到实际的值。
- STM32F1 上主输出和互补输出必须在同一种重映射里，比如 PE9 不能配 PB13。TIM1 的部分重映射只挪互补输出，CH1-CH4 还在 PA8-PA11。
- CH4 没有互补输出。PC6-PC8 写了 `complement` 时取 TIM8，不用写 `timer=8`。
- 占空比为 0.0 时主输出一直是低电平、互补输出一直是高电平，1.0 时相反。

## 精度

- 一个周期最多 65535 个计数，占空比的最小步长是 1 / 计数。
- 编译器优先找能整除的分频，但只在步数不少于最多步数一半的范围里找。找不到时取步数最多的分频，频率取最接近的。72 MHz 时，1.1 kHz 以下每个周期至少有约 22000 个计数，频率误差在 25 ppm 以内，比晶振本身的误差还小。
- 72 MHz 时：50 Hz 每个周期 60000 个计数（计数频率 3 MHz，`pulse_us` 的精度是 1/3 微秒），1 kHz 是 36000 个计数。
- 频率越高步数越少，上限是定时器时钟的一半，这时只剩 2 级。

## 注意

- PA15、PB3、PB4 复位后属于 JTAG，用到时编译器会自动处理，SWD 不受影响。
