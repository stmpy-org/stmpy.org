# 数字和运算

## int

`int` 是 32 位有符号整数，范围是 -2147483648 到 2147483647。

- **常量必须在这个范围内**，超出时编译报错。十六进制也一样，`0xFFFFFFFF` 放不进 `int`，要写成 `-1`。
- **常量表达式在编译时计算**，结果同样不能超出范围，比如 `1 << 31` 会报错。
- **运行时的溢出没有保证**：结果可能回绕，也可能被编译器按"不会溢出"优化掉。不要依赖溢出后的值。需要按 32 位处理的场合（比如 CRC、掩码），用 `& 0xFFFF` 这类写法把值限制在范围内。

`bool` 参与运算时当作 `int`：`True + 1` 等于 2。

## float

`float` 是 32 位单精度浮点数，有效数字大约 7 位，超过 16777216（2²⁴）的整数存成 `float` 会丢精度。

`int` 和 `float` 一起运算时，结果是 `float`。

目前没有把 `float` 转回 `int` 的办法，`int()` 还不支持。

## 除法

除法的规则和 Python 一致，**和 C 不同**：

| 写法 | 结果 | 例子 |
|---|---|---|
| `a / b` | 总是 `float` | `7 / 2` 是 `3.5` |
| `a // b` | 向下取整 | `7 // 2` 是 `3`，`-7 // 2` 是 `-4` |
| `a % b` | 符号和除数相同 | `-7 % 2` 是 `1` |

C 的整数除法是向零截断，`-7 / 2` 在 C 里是 `-3`。StmPy 生成的代码会按 Python 的规则算，负数时结果和 C 不一样。

`/` 的结果是 `float`，不能赋给 `int` 变量：

```python
x = 7
y: int = x / 2      # 报错：y 是 int，x / 2 是 float
z = x // 2          # 3
```

除数是常量 0 时编译报错。除数是运行时的变量并且等于 0 时，结果没有保证。

## 位运算

`&` `|` `^` `~` `<<` `>>` 只能用在 `int` 上。`>>` 是算术右移，负数右移后仍是负数。

把两个字节拼成一个有符号的 16 位数，是很常见的写法：

```python
x = (high << 8) | low
if x >= 0x8000:
    x -= 0x10000
```

## 比较

`int` 和 `float` 之间可以直接比较。不支持连续比较，`a < b < c` 要写成 `a < b and b < c`。
