StmPy Studio edits, builds and flashes firmware. StmPy translates your Python-syntax program to C on the STM32 HAL, so it runs as fast as hand-written C — with no interpreter on the chip.

<CardGrid>
	<Card title="Editor + language server" icon="pencil">
		Monaco with completion, hover and diagnostics. Pin arguments list the pins of your chip.
	</Card>
	<Card title="One-click build & flash" icon="rocket">
		Bundled stmpy, arm-none-eabi-gcc and probe-rs. No separate toolchain hunt.
	</Card>
	<Card title="Clock tree & project wizard" icon="setting">
		New projects pick a chip and clocks, then write a blinking LED in minutes.
